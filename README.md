A program that writes one short text to `/output/entry.txt`: a clockmaker's daughter who can hear what is wrong with any clock just by listening, and one morning hears beneath the tower's ticking a second ticking — slower, patient, keeping a time no one had set. The intrigue is shown, not instructed, and the image lingers after the last line. `main.py` (Python 3.13, stdlib only, no network) checks the text against the gate's caps (1–280 Unicode code points, not only white space) and writes it out deterministically.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
